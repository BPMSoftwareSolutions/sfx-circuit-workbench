# SideFX Circuit Workbench

Choose a runnable source view and select its input node. Contract-generated
controls collect the declared user input, then the dialog collapses into the
circuit. Reported execution observations illuminate the selected interface;
the returned outcome opens in a generated dialog at its outcome node.

Hello World, personal greeting, four retained provider examples and the live
stock-price capability use the authenticated remote SideFX service. SQL and
RapidAPI credentials remain on that service. The complete authoring blueprint
and native execution source views remain available for inspection. Runnable
interface views are explicitly scoped; they do not claim to show all internal
mechanics. The earlier Lab remains at `/lab`.

Required Space secrets: `SIDEFX_INVOCATION_ENDPOINT`, `SIDEFX_SERVICE_TOKEN`, and
`SIDEFX_LAB_ORIGIN` (the Space's HTTPS hf.space origin).
